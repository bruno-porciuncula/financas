# Finanças dos Porciunculas (app instalável)

Casca instalável (PWA) que abre o app do Google Apps Script em tela cheia.
Os dados ficam na planilha "Finanças dos Porciunculas (dados do app)" no Google Drive.

Para instalar no Android: abra o site no Chrome → menu ⋮ → "Instalar app".
Se o link do app do Google mudar, troque APP_URL em index.html.
